# horopter

The Horopter service and its CLIs. Specs, plans and decisions live in the private
`horopter-dev/horopter-internal`; the docs site in `horopter-dev/horopter-docs`.

## Agent skills

### Issue tracker

Linear, workspace `horopter`, team `HOR`; GitHub issues sync into it. See
`docs/agents/issue-tracker.md`.

### Triage labels

The five default role names, as `HOR` team labels. See `docs/agents/triage-labels.md`.

### Domain docs

Single-context, kept in the sibling `horopter-internal` checkout: its `CONTEXT.md` and
`decisions/`. See `docs/agents/domain.md`.
